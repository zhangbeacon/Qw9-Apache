> 用途：第九届强网拟态赛——选 Linux 开源基准程序 V1，做异构变体 V2/V3，复现 ≥3 个历史 CVE。

## 表一：GLM 报告筛选（5 款）

| 2 | **ProFTPD** | 1.3.5（拿 RCE）或 1.3.6a（内存安全×3） | CVE-2015-3306（pre-auth RCE）、CVE-2010-4261、CVE-2020-9272/9273、CVE-2019-18227 | Metasploit `proftpd_modcopy_exec`、Exploit-DB 36842 | 拟态差分教科书：类型最全；但单一钉版本无法同时吃下 3306 与 9272，需取舍 |
| 3 | **dnsmasq** | **2.77** | CVE-2017-14491~14496（7 个一波）+ DNSpooq CVE-2020-25681~25687 | Google 审计批、EDB 42941-42946、CERT VU#434904 | 单版本漏洞密度之王：一个版本白嫖 12+ CVE；代码最小、变体最快 |

## 总结

**1. 三份报告的共识（选型硬标准一致）**
- V1 必须钉在**含洞的历史版本**上（按 NVD Affected Versions 选），绝不能用最新 Release，否则复现环节 0 分；
- Linux x86-64、C/C++ 开源、体量适中（排除内核/浏览器级巨物与玩具程序）；
- 必须有**公开且可稳定复现的 POC**（GitHub / Exploit-DB / Metasploit / Vulhub）——硬指标；
- 优先网络服务接口或复杂外部输入解析；
- 异构变体套路一致：编译器（gcc/clang）× 优化等级 × 分配器（ptmalloc/jemalloc/tcmalloc）× 加固选项，变体后先验功能等价再跑 POC 矩阵。

**2. 交集与分歧**
- **nginx 是唯一三份全部上榜的软件**（但钉版本不同：GLM/GPT 钉 1.13.2，Qwen 钉 1.21.3）；
- **dnsmasq 两份头部上榜**（GLM 第 3 钉 2.77，GPT 第 1 钉 2.76，口径基本一致）；
- **Samba 两份上榜但都被警示**（代码量大/配置重/条件苛刻）；
- 首推互不相同：GLM→nginx、GPT→dnsmasq、Qwen→Apache httpd；
- 各自独有：GLM 独推 ProFTPD、memcached、libtiff；GPT 独推 ImageMagick、OpenSSL；Qwen 独推 Apache、Redis、CUPS。

**3. 口径差异提醒（重要）**
GPT 校正版明显更保守，直接纠正了另外两份的乐观表述：
- dnsmasq 2017 批公开 PoC 大多是 **DoS/ASAN 崩溃，不是稳定 RCE**；
- ImageMagick 的 CVE-2020-29599 在 6.x 无稳定 PoC，CVE-2023-34152 需显式开 `--enable-pipes`；
- vsftpd 2.3.4 的 CVE-2011-2523 只针对当年被植入后门的污染发行包，不能泛化；
- 采纳任何一方的"RCE"结论前，务必先对照 NVD 版本区间并在本机跑通 POC 再定稿。

**4. 综合决策建议**
- **主选（稳健）**：**nginx 1.13.2** —— 3 份报告全部命中、POC 生态最成熟（Vulhub/MSF/GitHub）、HTTP 自动化最容易，复现确定性最高；
- **副选（密度/小巧）**：**dnsmasq 2.76/2.77** —— 单版本 CVE 密度最高、代码最小、变体生成最快，适合冲"同版本复现数量"；
- **备选（易打/差异化）**：**Apache httpd 2.4.49**（curl 一行 RCE）或 **ImageMagick 6.9.3-3**（ImageTragick 五连，类型丰富度最高）；
- 赛前动作：把候选 CVE 逐个对照 NVD 版本区间确认"未修补"→ 在隔离环境跑通 POC → 再钉版本提交。
