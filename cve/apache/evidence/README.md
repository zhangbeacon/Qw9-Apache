# 判定摘要，不是本轮新实验

[返回唯一漏洞矩阵](../../../docs/02-漏洞矩阵.md)

本目录只保留 11 个 CVE 的历史判定摘要，来自固定发布快照 `0fedb25`，内容保持不变。本轮目录整理没有重跑实验。

完整访问/错误日志、原始请求与响应、构建记录和 fuzz 候选已进入[历史归档](../../../archive/README.md)，可按原路径在线核查或独立解包。不要把摘要当作完整证据，也不要拿旧摘要证明未来一轮成功。

各 CVE 父目录同时满足部分旧负向脚本的目录存在性前提；旧摘要的内容不是这些脚本的固定输入。

新实验请先使用独立的本轮证据目录，并按[协作规则](../../../docs/04-协作分工.md)审核、发布快照，不重新提交几百个临时输出。
