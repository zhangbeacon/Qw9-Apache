## 1. 先看结论

- 收录 **11 个 CVE**；历史记录为 **10 个动态复现，1 个仅静态定位与资源评估**。
- V1 是 Apache httpd 2.4.49。2.4.50 是版本差分对照；Ubuntu 2.4.52 是发行版回移补丁负向对照，均不等于 V2/V3 成果。
- 六个计分候选为 41773、44224、44790、22720、25690、38474；组合仍需最终确认。42013 与 41773 同根因，不重复计分。
- **最大的缺口不是再收集 CVE，而是 V2/V3、功能一致性与同 PoC 三版本矩阵。**

## 4. 挖掘与 fuzz 的成果边界

- 11 个 CVE 的修复 hunk 已定位，见[补丁差分研究摘要](research/补丁差分研究.md)。
- 44790 定向 fuzz 历史记录为 **60 个候选、8 个可单发回放、52 个回放失败**；这是已知漏洞的再发现，不是新漏洞。
- 旧报告的“v4 运行中”不是当前作业状态；当前没有可据此声称已完成的新总结。
