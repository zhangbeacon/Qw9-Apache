## 4. 结论

上一版（v1）的问题不是"事实边界写多了"，而是：

1. **没有逐条对照官方评分表**，把 20 分创新性和 4 分攻击链加分放在架构边缘；
2. **把两项核心创新降级**——LLM 监管写成"可选"，熵写成"不能替代安全增益的探索指标"；
3. **丢失了 Word v2 的三项机制**：类型分派、原语指纹、拟态网关/攻击链；
4. **丢掉了互补性筛选**，而这正是"两个变体为什么是这两个"的说明。

v2 修订原则：**创新点回到架构中心，事实边界保留在证据与状态层**。两者不矛盾——创新可以是"设计已定义、实现待完成"，但不能写成"已实现"。

修订后的设计与架构图见 [系统架构设计 v2](系统架构设计-v2.md)。
