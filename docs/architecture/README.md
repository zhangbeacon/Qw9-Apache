## 两条核心创新

1. **LLM 监管 Agent**：执行层／监管层／裁决层三层分离。监管层负责构建、变换审查、测试、资源、采证五项值守；L1 白名单可自动处置，L2 改参数必须人审；所有动作写入 `journal.jsonl`。**它没有判定权**，PASS/FAIL 只由机器判定门给出。
2. **可复现性熵 H(i)**：用 K 个内部结构扰动 × m 次重复，测量漏洞在不同变体上的三态分布，把"多样性是否抑制稳定利用"变成可计算、可比较的指标。熵必须与攻击成功率、配对迁移率、有效性分母联合解读。

## 五项支撑机制

类型分派异构（逻辑型→V3 重构，内存型→V2 加固）· 互补性筛选（校准集抑制率 + 留出验证）· 原语级指纹（泄露/崩溃/走私/SSRF 自动量化）· Evidence-as-Code（防陈旧证据守卫）· 多阶段攻击链与拟态网关（对应官方 4 分加分）。

## 两条实验轨道

- **轨道 E（熵）**：构建级扰动，运行配置恒定，只测内部结构敏感性；
- **轨道 P（作品）**：从候选中选出 V2/V3，可叠加等价重构与攻击面收敛，逐项声明。

两条轨道统计口径分开，避免把配置敏感性当成内部多样性。

## 事实边界

V2/V3 未构建、功能门与互补筛选未实现、三版本矩阵未运行、监管 Agent 未实现、熵无任何数值、网关与攻击链未建。任何"已提升安全""抑制率 X%""熵为 Y"的说法，在 M5 完成前都不成立。
