# Qw9-Apache

**以 Apache httpd 2.4.49 为基线，研究异构变体能否改变同一攻击的效果。**

这是第九届强网拟态的协作项目，不是 CVE 资料合集。主线只有一条：

```text
V1 漏洞基线 → 构造 V2 / V3 → 验证正常功能一致 → 同一 PoC 对比 → 评估安全增益
   已有基础         待实施             待实施               待实施            待实施
```

## 当前做到哪了

- **已有基础**：V1 选型、11 个 CVE 的脚本与分析；历史记录中 10 个动态复现，1 个仅静态定位。
- **真正的下一步**：构建 V2/V3，补齐功能一致性与同 PoC 三版本实验。修复版负向对照不等于异构变体成果。
- **状态边界**：本次是整理已有记录，未重新运行 PoC；具体状态只维护在下面的漏洞矩阵，不多处抄表。
